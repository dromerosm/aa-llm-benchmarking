Key Definitions

Output Speed

Tokens per second received while the model is generating tokens, after the first chunk has arrived.

Latency (Time to First Token)

Time between sending the request and receiving the first token. For non-streaming models, this reflects time to completion.

Time to First Answer Token

Time between sending the request and receiving the first answer token. For reasoning models, this comes after any thinking phase.

Price

Blended price in USD per million tokens, using a 3:1 ratio of input tokens to output tokens.

Input and Output Price

API prices in USD per million tokens for request tokens sent and completion tokens generated.

Time period

Artificial Analysis describes these metrics as live and based on the past 72 hours of measurements.
