Key Definitions

ELO

Artificial Analysis publishes ELO-style quality scores for these media endpoints. Higher values indicate stronger comparative performance inside the same benchmark family.

Endpoint Rank

Position by ELO within each endpoint, so rank 1 can appear once per endpoint family.

CI95

Confidence interval around the reported ELO score, as published by Artificial Analysis.
